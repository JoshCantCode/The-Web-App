# 🗺️ The Web App — Roadmap

This roadmap outlines the planned features and improvements for **The Web App**, a collaborative desktop chat app tailored for **developer teams**, **startups**, and **open-source communities**.

The Web App combines the best of **Slack/Discord** (chat), **VSCode** (live editing), and **GitHub** (workflow integration) into a focused, developer-first desktop experience.

---

## ✅ MVP (v0.1) – Core Chat Experience

> 💡 Establishing a baseline developer-friendly chat app

- [x] Create and join servers
- [x] Create/delete channels and categories
- [x] Send basic text messages
- [x] Favourite channels

---

## 🔜 Milestone 1 – Essential Improvements (v0.2)

> 🧱 Core chat & UX enhancements

- [ ] ✏️ Edit and delete messages
- [ ] 💬 Typing indicators (channel-based)
- [ ] 🎯 Message mentions (`@user`, `@everyone`, etc.)
- [ ] 📌 Pin messages per channel
- [ ] 🔔 Channel unread indicators
- [ ] 🧑‍🤝‍🧑 Add user presence (online/offline indicators)
- [ ] 🖼️ Upload and send images (JPEG, PNG, WebP)
- [ ] 🎞️ Embed GIFs (with preview support and autoplay toggle)
- [ ] 📁 Drag-and-drop file/image upload
- [ ] 📷 Image preview in messages

---

## 🧪 Milestone 2 – Developer Tools (v0.3)

> 👨‍💻 Real-time collaboration for dev teams

- [ ] 🔗 Connect GitHub repos to servers
- [ ] 📂 Display file tree or commit history from connected repo
- [ ] 💻 Start "Dev Session" – Live code sharing in Monaco or embedded editor
- [ ] 🔄 Collaborative editing (basic real-time sync)
- [ ] 🧩 Dev session terminal (optional: sandboxed shell for commands)
- [ ] 📝 Share code snippets with syntax highlighting

---

## 🤝 Milestone 2.5 – Friends & Private Chat (v0.3.5)

> 👥 Personal connections and community onboarding

- [ ] 👤 Add/remove friends
- [ ] 💬 Direct messages (DMs)
- [ ] 🌐 Custom profile status
- [ ] 📌 Shared media in DMs
- [ ] 🛑 Block/report users

*Note: While not a core focus, friend-related features support independent devs and small communities using The Web App for casual collaboration.*

## 🖌️ Milestone 4 – UI/UX Polish & Desktop Integration (v0.5)
