# The Web App

**The Web App** is a modern desktop collaboration tool built specifically for developer teams. It combines real-time chat, GitHub integration, and live coding sessions—bringing the core tools of development into a single streamlined interface.

Focusing on optimization, The Web App is built with Tauri, a desktop app framework in Rust.

---

## 🚀 Features

- 💬 **Real-Time Chat**  
  Organize conversations by servers, categories, and channels—just like you'd expect in a modern dev environment.

- 🧠 **GitHub Integration**  
  Connect your GitHub repositories directly to your servers for streamlined collaboration.

- 💻 **Dev Sessions**  
  Launch live coding sessions inside your chat environment. Collaborate as if you're sharing a VS Code plugin—ideal for pair programming, mentoring, or debugging together.

- 🛠️ **Team Organization**  
  Create and manage servers, roles, and developer-specific permissions tailored to team workflows.

- 🌐 **Cross-Platform Desktop**  
  Built with Tauri for lightweight, cross-platform performance on Windows, macOS, and Linux.

## 🧱 Tech Stack

| Layer         | Technology                     |
| ------------- | ------------------------------ |
| Frontend      | [Next.js](https://nextjs.org/) |
| Styling       | [Tailwind CSS](https://tailwindcss.com/), [shadcn/ui](https://ui.shadcn.com/) |
| Auth          | [better-auth](https://www.npmjs.com/package/better-auth) |
| Desktop Shell | [Tauri](https://tauri.app/)    |
| Database      | [Neon](https://neon.tech/) (PostgreSQL-compatible serverless DB) |
| API           | [NestJS](https://nestjs.com)   |
| Hosting       | [Railway](https://railway.com)   |
